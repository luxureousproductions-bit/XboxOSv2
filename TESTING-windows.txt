XboxOSv2 - Windows test build (windows-wip branch)

INSTALL
1. Download the windows-wip branch from GitHub (switch the branch to
   windows-wip, then Code > Download ZIP) and extract it into your Pegasus
   themes folder.
2. Rename the extracted folder to the name your old XboxOSv2 folder had.
   Pegasus keeps theme settings per folder name, so a new name starts from
   defaults.

VIDEOS (black screens)
Pegasus plays video through Windows' own DirectShow, which can't open .mp4
on a stock Windows install. Pegasus's Windows guide recommends a codec pack:
  - Install the K-Lite Codec Pack Basic, then restart Pegasus.
    (Pegasus for Windows is a 32-bit program; K-Lite includes the 32-bit
    decoders it needs.)
Without codecs the theme now shows the game's art instead of black, and
Discover says what to install. Each failed video is listed in lastrun.log
as "XboxOSv2: video could not play".
Note: preview videos are OFF by default on Windows. Turn them on in Settings
to test them (Tiles, All Games and Game details > Video previews).

TEST LAUNCHER (optional, in the zip's extras)
"Pegasus test launcher.bat": put it next to pegasus-fe.exe and use it to
start Pegasus. It writes your graphics driver details to lastrun.log and
turns on Qt's threaded drawing, which is usually smoother.

FRAME COUNTER
Press Ctrl+F on a keyboard to show frames per second (top left). Read it
WHILE scrolling: about 60 is smooth. Note which screen drops and whether
High Quality Mode, Tile Halo or Dynamic Background change it.

WHAT'S NEW IN THIS BUILD
- System tiles: sharper. Base mode = 1080p detail, High Quality Mode =
  full detail for your screen (up to 4K).
- Less work per move: the home background decodes at 1080p size in base
  mode on big screens; tile glows are only built when switched on.
- Game details no longer goes black when its video can't start.
- Hero box follows the last game you launched.

IF SOMETHING GOES WRONG
Send the steps right before it and config/lastrun.log from your Pegasus
folder.
