# harness-pegasus

Not part of the theme. This branch only holds the stock Pegasus build the
XboxOSv2 test harness runs on: `pegasus-fe_alpha16-107-g5d58223e_x11-static.zip`
(Linux x11 static, from mmatyas/pegasus-frontend's continuous release,
2026-10-02; GPLv3, see PEGASUS-LICENSE.md). It lives here because Claude's cloud
sessions can clone repos but can't download GitHub release files.

`tools/harness/setup.sh` on the `refresh` branch fetches it automatically.
